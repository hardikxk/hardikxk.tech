# hardikxk.tech

Personal portfolio website for Hardik Kumar, showcasing work across compilers, deep learning, and distributed systems.

## Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Runtime & Package Manager:** [Bun](https://bun.sh/)
- **Language:** TypeScript

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (v1.4+)

### Installation

```bash
bun install
```

### Development

```bash
bun dev
```

The site will be available at `http://localhost:3000`.
